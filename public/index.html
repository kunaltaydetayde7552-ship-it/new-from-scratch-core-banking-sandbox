About

How this sandbox behaves.

Banking rules (demo)

  • Balances and transfers use Indian Rupees (₹).
  • Transfers require sufficient funds unless overdraft is enabled by admin settings.
  • Account numbers and customer data are synthetic.

Demo limits

  • Data is stored in your browser only (local persistence).
  • No authentication to external banks or payment rails.
  • Intended for learning and API integration testing in PST_PD_153 scope.

Synthetic data notice

All names, account numbers, and transaction histories are generated for demonstration. Do not use real personal or financial information.
